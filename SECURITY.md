# Security Policy for This Portfolio Repository

This repository is a curated engineering portfolio, not the authoritative Snowwave source repository.

## Intentionally excluded

Do not commit:

- credentials, tokens, keys, connection strings, or secrets;
- real Azure resource names where unnecessary;
- tenant, subscription, object, application, or principal identifiers;
- private deployment URLs or SAS URLs;
- internal operational handoffs;
- workflow run IDs and incident-specific infrastructure identifiers;
- private customer, employee, parcel, route, or operational data;
- the `.git` history of the private Snowwave repository.

## Reporting

If you notice material in this public portfolio that appears environment-specific or sensitive, treat it as a publication defect and remove/review it before making the repository public.

## Scope

Examples in this repository are selected and sanitized representations of engineering patterns from a non-production portfolio system. They should not be interpreted as credentials, production configuration, or a complete deployable environment.
